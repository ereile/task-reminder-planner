# Task & Reminder Planner

Модуль планировщика задач и напоминаний.

## Возможности
- создание/редактирование/удаление задач;
- приоритеты и сроки выполнения;
- напоминания к задачам;
- фильтрация по статусу.

## Структура
- `src/` — исходный код
- `tests/` — тесты
- `docs/` — документация и UML

## Запуск
python src/main.py
