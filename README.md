# Task & Reminder Planner

Модуль планировщика задач и напоминаний (вариант 8).

## Возможности
- Напоминания с настраиваемым временем
- Повторяющиеся задачи (daily/weekly/monthly)
- Экспорт в iCal (.ics)
- API для фильтрации задач

## Стек
FastAPI, python-dateutil, icalendar, pytest, Black, Pylint, GitHub Actions.
