# QA Чек-лист (Ручное тестирование)

## Позитивные сценарии
- [ ] **Создание задачи с напоминанием:** Создать задачу с `reminder_offset_minutes=15`. Ожидается: в ответе API есть поле `remind_at` на 15 минут раньше `due_date`.
- [ ] **Повторяющиеся задачи:** Создать задачу с `recurrence="daily"`, нажать "Выполнено". Ожидается: создается копия задачи на следующий день.
- [ ] **Фильтрация:** Запросить `GET /tasks?priority=high`. Ожидается: возвращаются только задачи с высоким приоритетом.
- [ ] **Экспорт в iCal:** Запросить `GET /tasks/export.ics`. Ожидается: скачивается файл `.ics`, который успешно импортируется в Google Calendar.
- [ ] **Переход по месяцам:** Создать задачу на 31 января с `recurrence="monthly"`, нажать "Выполнено". Ожидается: следующая задача создается на 28 (или 29) февраля.

## Негативные сценарии
- [ ] **Пустое имя задачи:** Отправить `POST /tasks` с пустым `title`. Ожидается: ошибка валидации (422).
- [ ] **Несуществующая задача:** Вызвать `PATCH /tasks/random-id/done`. Ожидается: ошибка 404 (Task not found).
- [ ] **Неверный формат даты:** Отправить `due_date="вчера"`. Ожидается: ошибка валидации (422).
