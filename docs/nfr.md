# Нефункциональные требования

## Производительность
- Отклик `GET /tasks` при 1000 задачах — не более 200 мс.
- Генерация `.ics` для 100 задач — не более 1 секунды.

## Безопасность
- Валидация входных данных через Pydantic (типы, обязательные поля).
- Отсутствие секретов в коде (`.env` в `.gitignore`).
- Ответы API не раскрывают внутренних путей файловой системы.

## Ограничения
- Один пользователь (без аутентификации) — в рамках MVP.
- Хранение — JSON-файл, без СУБД.
- Напоминания выводятся в лог/консоль, без внешних каналов.

## Совместимость
- Python 3.11+.
- Экспорт iCal соответствует RFC 5545.
- Файлы `.ics` открываются в Google Calendar, Apple Calendar, Outlook.

## Стек технологий
| Слой | Технология | Обоснование |
|---|---|---|
| API | FastAPI | Swagger UI «из коробки», валидация |
| Хранение | JSON-файл | Без БД для MVP |
| Повторения | python-dateutil | Корректная работа с месяцами |
| iCal | icalendar | Соответствие RFC 5545 |
| Тесты | pytest + pytest-cov | Отчёт покрытия |
| Стиль | Black + Pylint | Автоформат + линт в CI |
